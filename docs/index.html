Design

    
Why HTML-first

  

  

    
Interactivity is content

      
Filters, charts and tabs are ordinary markup — no plugin syntax, no iframes, no build step
      to render them.

    
One registry

      
assets/toc.js plus small part files. Add a page, add an entry — nav, search
      and prev/next wire themselves.

    
Machine-checkable

      
pustaka check validates structure, links, asset prefixes and registry
      consistency. Run it in CI; hand it to an AI.

    
No third-party requests

      
Fonts and ECharts are vendored. The docs render identically offline, air-gapped, or behind
      a strict CSP.
