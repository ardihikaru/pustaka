Production deployment

One- or two-sentence summary. Indexed as the page's search description.

Two ways to ship

Push the docs/ folder to any static host (GitHub Pages, Nginx, S3). Search runs from the ToC sections; navigation uses full page loads.

bash
go build -o pustaka .
./pustaka serve ./docs --addr :8080 --prod   # --prod caches the index

Put it behind your reverse proxy: one process serves, indexes, gzips, and answers HTMX partials.

Run it as a service

ini
# /etc/systemd/system/pustaka.service
[Unit]
Description=Pustaka docs
After=network.target

[Service]
ExecStart=/opt/pustaka/pustaka serve /opt/pustaka/docs --addr :8080 --prod
Restart=on-failure

[Install]
WantedBy=multi-user.target

Why this page is two folders deep

This file lives at guide/deploy/production.html — created with pustaka new, which computed the ../../ asset prefix and registered it automatically. Folders are the tidy way to grow a product's docs.
