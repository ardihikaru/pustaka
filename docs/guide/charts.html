Concept

Interactive charts

The clearest argument for HTML-first docs. These are live Apache ECharts instances: drag the zoom brush, hover the tooltips, toggle the legend — then flip the theme (moon icon) and watch them re-render from the site’s design tokens.

Why ECharts

  • Canvas rendering — smooth with tens of thousands of points.
  • Interactions built-in — tooltip, dataZoom, legend, toolbox; zero custom JS.
  • Impossible in Markdown — mkdocs needs plugins + iframes; here it is one <div> and one init().

The embedding pattern

html + js
<div class="chart" id="my-chart"></div>

const chart = echarts.init(document.getElementById('my-chart'));
chart.setOption({ /* option built from CSS variables */ });

// re-skin when the site theme flips
document.addEventListener('pustaka:theme', rebuild);

Tip — lazy init

Initialize charts inside an IntersectionObserver so canvases below the fold cost nothing until scrolled into view — this page does exactly that.
