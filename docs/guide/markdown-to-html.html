Convert Markdown to HTML

Turn an existing Markdown document into a complete Pustaka page without losing structure, searchability, or the static-file workflow.

Convert the source

Ask Pandoc for a body fragment, not a complete document. GitHub-Flavored Markdown is a useful default when the source contains task lists, fenced code, or tables.

shell
pandoc input.md --from=gfm --to=html5 --output=fragment.html

Fragment versus standalone

Do not add --standalone for this step. Pustaka already supplies the doctype, metadata, stylesheets, shell, and runtime scripts.

Fit the Pustaka template

  1. Copy docs/_template.html to the intended kebab-case path.
  2. Paste the converted fragment inside <main class="doc">.
  3. Keep the eyebrow, one h1, a concise .lede, and the runtime scripts.
  4. Apply one ../ asset prefix per folder level.
html
<p class="eyebrow">Guide</p>
<h1>Imported runbook</h1>
<p class="lede">What this runbook solves and who should use it.</p>

<h2 id="prepare">Prepare</h2>
<p>Converted body content…</p>

Repair semantics

Pandoc produces valid HTML, but the page contract is stricter. Give every h2 a unique kebab-case id, turn extension-specific admonitions and tabs into Pustaka components, and keep page scripts as the final children of main.doc.

Markdown sourcePustaka result
## Install<h2 id="install">Install</h2>
Fenced code.codeblock with a copy button
Extension admonition.adm.note, .tip, or .warn
Raw HTMLReview and sanitize before publishing

Treat imported HTML as code

Never publish untrusted conversion output without sanitizing it. Remove scripts, event-handler attributes, unsafe URLs, embedded objects, and markup that violates your content security policy.

Register and check

Add the leaf to the relevant ToC part, including searchable section summaries, then use the checker as the acceptance gate.

shell
go build -o pustaka .
./pustaka check ./docs
./pustaka serve ./docs

See Page metadata when the imported document needs tags, publication dates, or a system-version range.
