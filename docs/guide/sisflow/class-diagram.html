Class diagrams

Render UML-style classes with stereotypes, attributes, methods, visibility, and association, inheritance, aggregation, composition, and dependency relationships.

Live class-diagram workbench

The boxed workbench starts editable and demonstrates every supported relationship marker.

Live class-diagram viewer

The unboxed viewer fixes the generated layout with the engine-wide read-only gate.

Fixed and read-only contract

The layered layout deterministically places classes from top to bottom. With readOnly: true, readers may inspect and navigate the result but cannot drag a class, edit a member, reshape a relationship, or execute graph mutations.

javascript
import sisflow from './vendor/sisflow/index.js';
import { SISMAYA_LIGHT } from './vendor/sisflow/theme/themes.js';
import { defineClassShapes } from './vendor/pages/class-diagram-setup.js';

sisflow.themes.register('docs-light', SISMAYA_LIGHT);
const container = document.querySelector('#diagram'); // position:relative; height:520px
const member = (name, type, visibility = '-') => ({ name, type, visibility, static: false });
const model = {
  sisflow: 1,
  nodes: [
    { id: 'Shape', shape: 'classbox', x: 300, y: 40, data: { kind: 'class', name: 'Shape',
      abstract: true, attributes: [member('x', 'float'), member('y', 'float')],
      methods: [{ ...member('area', 'float', '+'), params: [], abstract: true }] } },
    { id: 'Circle', shape: 'classbox', x: 120, y: 300, data: { kind: 'class', name: 'Circle',
      abstract: false, attributes: [member('radius', 'float')],
      methods: [{ ...member('area', 'float', '+'), params: [], abstract: false }] } },
    { id: 'Canvas', shape: 'classbox', x: 500, y: 300, data: { kind: 'class', name: 'Canvas',
      abstract: false, attributes: [member('name', 'string')], methods: [] } }
  ],
  edges: [
    { id: 'inherit', from: 'Circle', to: 'Shape', shape: 'inherit',
      data: { kind: 'inherit', markers: { start: null, end: 'triangle' } } },
    { id: 'compose', from: 'Shape', to: 'Canvas', shape: 'compose',
      data: { kind: 'compose', markers: { start: null, end: 'diamond-filled' },
        fromLabel: '0..*', toLabel: '1' } }
  ]
};
const flow = sisflow.create(container, {
  renderer: 'canvas', theme: 'docs-light', readOnly: true,
  layout: sisflow.layouts.layered({ direction: 'down' }),
  edges: { route: 'ortho', corner: 6, jumpOver: true }
});
defineClassShapes(flow);
flow.graph.load(model);
flow.commands.zoomToFit(24);
const toggleFullscreen = (target) => document.fullscreenElement
  ? document.exitFullscreen() : target.requestFullscreen();
document.querySelector('#canvas-full').onclick = () => toggleFullscreen(container);
document.querySelector('#viewer-full').onclick = () => toggleFullscreen(document.querySelector('#viewer'));
document.addEventListener('fullscreenchange', () => { flow.resize(); flow.commands.zoomToFit(24); });
document.querySelector('#export').onclick = () => saveSVG(flow.export.toSVG({ padding: 16 }));
addEventListener('beforeunload', () => flow.dispose());
function saveSVG(text) {
  const url = URL.createObjectURL(new Blob([text], { type: 'image/svg+xml' }));
  const a = Object.assign(document.createElement('a'), { href: url, download: 'class-diagram.svg' });
  a.click(); URL.revokeObjectURL(url);
}

Canvas and viewer fullscreen

Target the canvas for a pure UML presentation or the viewer wrapper to retain its controls. Always resize and refit on both entry and exit; iframe hosts need allow="fullscreen".

Rebuild and disposal

Dispose the current surface before rebuilding, then define class shapes, load the unchanged canonical model, and fit the new instance.
