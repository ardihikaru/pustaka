System architecture diagrams

Present services, people, data stores, external systems, and nested boundaries as an editable Sisflow workbench or a fixed read-only architecture viewer.

Live architecture workbench

The boxed sample exercises boundary containment, tagged styles, scoped layout, orthogonal, direct and curved routes, theme rebuilding, SVG export, and both fullscreen scopes.

Live architecture viewer

The unboxed viewer starts read-only and omits editor chrome while retaining pan, zoom, fit, export, canvas fullscreen, and complete-viewer fullscreen.

Fixed and read-only contract

Set readOnly: true when creating the instance. The scoped layout produces the fixed presentation from node.parent; readers cannot reparent, drag, edit, reshape, or invoke a mutating command, but all viewport commands remain available.

Complete runnable sample

After copying ZRender and web/static/js into vendor/, this module creates a complete nested architecture document. The HTML host is the same explicit-height container shown on the ERD page.

html
<!doctype html>
<meta name="viewport" content="width=device-width">
<style>html,body,#viewer{margin:0;height:100%}#diagram{position:relative;height:calc(100% - 42px)}</style>
<script src="./vendor/vendor/zrender.min.js"></script>
<div id="viewer"><div id="diagram" tabindex="0"></div>
  <button id="canvas-full">Canvas fullscreen</button>
  <button id="viewer-full">Viewer fullscreen</button>
  <button id="export">Export SVG</button></div>
<script type="module" src="./architecture.js"></script>
javascript
import sisflow from './vendor/sisflow/index.js';
import { SISMAYA_LIGHT } from './vendor/sisflow/theme/themes.js';
import { defineArchitectureShapes, normalizeArchitectureDoc }
  from './vendor/pages/architecture-editor-setup.js';

sisflow.themes.register('docs-light', SISMAYA_LIGHT);
const container = document.querySelector('#diagram');
const architecture = {
  sisflow: 2,
  nodes: [
    { id: 'shop', shape: 'boundary', data: { label: 'Digital Shop' } },
    { id: 'customer', shape: 'archcard', tags: ['person'], x: 20, y: 180,
      data: { label: 'Customer', perspectives: { context: true } } },
    { id: 'web', parent: 'shop', shape: 'archcard', tags: ['service'], x: 220, y: 80,
      data: { label: 'Web App', perspectives: { runtime: true } } },
    { id: 'db', parent: 'shop', shape: 'archcard', tags: ['datastore'], x: 500, y: 80,
      data: { label: 'Orders DB', perspectives: { data: true } } }
  ],
  edges: [
    { id: 'browse', from: 'customer', to: 'web', tags: ['sync'], data: { label: 'Browses' } },
    { id: 'store', from: 'web', to: 'db', tags: ['sync'], data: { label: 'Reads/writes' } }
  ],
  styles: {
    nodes: [
      { tag: 'service', shape: 'pill', fill: '#e8f4ff', stroke: '#2563eb', text: '#172554' },
      { tag: 'datastore', shape: 'roundRect', fill: '#fff7ed', stroke: '#b45309', text: '#431407' },
      { tag: 'person', shape: 'diamond', fill: '#ecfdf5', stroke: '#047857', text: '#064e3b' }
    ],
    edges: [{ tag: 'sync', thickness: 3 }]
  }
};

const flow = sisflow.create(container, {
  renderer: 'canvas', theme: 'docs-light', readOnly: true,
  layout: sisflow.layouts.scoped({ direction: 'right' }),
  edges: { route: 'ortho', corner: 6, jumpOver: true }
});
defineArchitectureShapes(flow);
flow.graph.load(normalizeArchitectureDoc(architecture));
flow.commands.zoomToFit(24);

const toggleFullscreen = (target) => document.fullscreenElement
  ? document.exitFullscreen() : target.requestFullscreen();
document.querySelector('#canvas-full').onclick = () => toggleFullscreen(container);
document.querySelector('#viewer-full').onclick = () => toggleFullscreen(document.querySelector('#viewer'));
document.addEventListener('fullscreenchange', () => { flow.resize(); flow.commands.zoomToFit(24); });
document.querySelector('#export').onclick = () => saveSVG(flow.export.toSVG({ padding: 16 }));
addEventListener('beforeunload', () => flow.dispose());
function saveSVG(text) {
  const url = URL.createObjectURL(new Blob([text], { type: 'image/svg+xml' }));
  const a = Object.assign(document.createElement('a'), { href: url, download: 'architecture.svg' });
  a.click(); URL.revokeObjectURL(url);
}

Canvas and viewer fullscreen

Request fullscreen on the canvas for a presentation-only surface or on its wrapper to retain viewer controls. Give an embedding iframe allow="fullscreen", and resize plus fit on every fullscreenchange, including exit.

Rebuild and disposal

Dispose before replacing an instance or switching its creation-time theme/read-only state. Keep the canonical model unchanged and load it into the replacement before fitting.
