Org chart editor

Edit a tree-shaped organization chart with inline labels, add-child controls, and collapsible branches while keeping the underlying reporting tree fixed.

Live org-chart-editor workbench

The workbench keeps the hierarchy visible while letting you edit labels, add direct reports, and collapse or expand branches. It is a tree editor first, not a general-purpose canvas, and the fullscreen control turns it into a proper editing surface.

Live org-chart-editor viewer

The viewer removes edit affordances and keeps the chart in a read-only inspection mode for browsing the hierarchy, roles, and branch structure. Use fullscreen to read the tree as a single vertical story instead of a sidebar-sized preview.

Tree-editor workflow

The editor workflow is intentionally narrow: select a node, adjust the text, append a child, or collapse a branch. That keeps the UI close to the mental model of an org chart, where the shape of the hierarchy matters more than freeform layout.

ActionResult
Edit labelUpdates the person name or role in place.
Add childCreates a direct report under the selected manager.
Collapse branchHides descendants without changing the tree model.
ResetRestores the canonical org tree from the source model.

Fixed and read-only contract

Freeze mode disables text editing and branch mutation. The hierarchy stays intact, and the viewer still serves as an inspection surface for the reporting structure and level accents.

Complete runnable sample

The runnable sample is a recursive tree renderer with inline editing and branch controls. The same source model can be swapped into a workbench iframe or a viewer iframe without changing the data itself.

html
<!doctype html>
<meta name="viewport" content="width=device-width">
<iframe id="org-chart" src="../../assets/vendor/sisflow/org-chart-editor-demo.html?mode=workbench"
  allow="fullscreen" style="width:100%;height:760px;border:0;border-radius:16px"></iframe>

<script type="module">
  const frame = document.querySelector('#org-chart');
  // Rebuild from the same canonical tree when switching modes.
  const setMode = (mode) => { frame.src = `../../assets/vendor/sisflow/org-chart-editor-demo.html?mode=${mode}`; };
  setMode('workbench');
  // setMode('viewer');
</script>

Fullscreen and embedding

Fullscreen the iframe or its wrapper from a click handler. The embedded document is still responsible for the tree controls, so the host only needs to grant fullscreen access.

javascript
toggle.onclick = async () => {
  if (document.fullscreenElement) await document.exitFullscreen();
  else await document.querySelector('#org-chart').requestFullscreen();
};

Lifecycle

Dispose the current tree before changing mode or replacing the source model. That preserves the canonical hierarchy and avoids mixing old branch state with a new tree.
