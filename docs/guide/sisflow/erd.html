Entity-relationship diagrams

Embed an offline Sisflow ERD as an editable workbench or as a fixed, read-only viewer without an entity sidebar.

Live ERD workbench

The boxed variant starts editable. Its entity panel filters a derived view without changing the canonical model; Freeze drawing rebuilds the engine with the real read-only gate.

Live ERD viewer

This unboxed variant has no entity sidebar and starts with readOnly: true. Pan, zoom, fit, both fullscreen scopes, and SVG export remain available.

Fixed and read-only contract

RequirementImplementation
Block all mutationsCreate the instance with readOnly: true; mutating commands, drag, edge drawing, reshape, and text editing are gated by the engine.
Keep positions fixedUse authored x/y values or one deterministic layout. Read-only prevents readers from changing the result.
No entity sidebarMount only the canvas. Visibility controls are host UI, not required by Sisflow.
Keep navigationRead-only deliberately retains selection, pan, wheel zoom, hand mode, fit, fullscreen, and export.

Complete runnable sample

Vendor ZRender and web/static/js from sisflow-js, then place these files beside that vendor/ folder. The smaller document is complete and uses the same entity face and relationship markers as the live model.

html
<!doctype html>
<meta name="viewport" content="width=device-width">
<style>
  html, body { margin: 0; height: 100%; }
  #erd { position: relative; width: 100%; height: 100%; background: #f9fafb; }
  #erd:fullscreen { width: 100vw; height: 100vh; }
</style>
<script src="./vendor/vendor/zrender.min.js"></script>
<div id="erd" tabindex="0"></div>
<button id="viewer-full" type="button">Viewer fullscreen</button>
<button id="export" type="button">Export SVG</button>
<script type="module" src="./erd.js"></script>
javascript
import sisflow from './vendor/sisflow/index.js';
import { SISMAYA_LIGHT } from './vendor/sisflow/theme/themes.js';
import { defineErdShapes } from './vendor/pages/erd-shapes.js';

sisflow.themes.register('docs-light', SISMAYA_LIGHT);
const container = document.querySelector('#erd');
const documentModel = {
  sisflow: 1,
  nodes: [
    { id: 'customer', shape: 'entity', x: 40, y: 80, data: { kind: 'table', name: 'customer', fields: [
      { name: 'id', type: 'INT', pk: true, nullable: false },
      { name: 'email', type: 'VARCHAR(190)', unique: true, nullable: false }
    ] } },
    { id: 'orders', shape: 'entity', x: 360, y: 80, data: { kind: 'table', name: 'orders', fields: [
      { name: 'id', type: 'INT', pk: true, nullable: false },
      { name: 'customer_id', type: 'INT', fk: true, nullable: false,
        ref: { table: 'customer', column: 'id' } }
    ] } }
  ],
  edges: [{ id: 'fk-orders-customer', from: 'orders', to: 'customer', shape: 'rel',
    data: { kind: 'fk', markers: { start: 'zero-many', end: 'one' },
      fromColumns: ['customer_id'], toColumns: ['id'] } }]
};

const flow = sisflow.create(container, {
  renderer: 'canvas', theme: 'docs-light', readOnly: true,
  layout: sisflow.layouts.layered({ direction: 'right' }),
  edges: { route: 'ortho', corner: 6, jumpOver: true }
});
defineErdShapes(flow);              // define before graph.load()
flow.graph.load(documentModel);     // keep this canonical object unchanged
flow.commands.zoomToFit(24);

document.querySelector('#viewer-full').onclick = () =>
  (document.fullscreenElement ? document.exitFullscreen() : container.requestFullscreen());
document.addEventListener('fullscreenchange', () => {
  flow.resize(); flow.commands.zoomToFit(24);
});
document.querySelector('#export').onclick = () => download('erd.svg', flow.export.toSVG());
addEventListener('beforeunload', () => flow.dispose());

function download(name, text) {
  const url = URL.createObjectURL(new Blob([text], { type: 'image/svg+xml' }));
  const a = Object.assign(document.createElement('a'), { href: url, download: name });
  a.click(); URL.revokeObjectURL(url);
}

Canvas and viewer fullscreen

Request fullscreen from the click handler itself so browser user activation is preserved. Inside an iframe, the parent must include allow="fullscreen". Target the canvas for a pure presentation surface, or a wrapper element to retain the viewer toolbar.

javascript
async function toggleFullscreen(target) {
  if (document.fullscreenElement) await document.exitFullscreen();
  else await target.requestFullscreen();
}

canvasButton.onclick = () => toggleFullscreen(container); // canvas only
viewerButton.onclick = () => toggleFullscreen(viewerRoot); // complete viewer
document.addEventListener('fullscreenchange', () => {
  flow.resize();
  flow.commands.zoomToFit(24);
});

Rebuild and disposal

Theme, visibility, and read-only are creation-time state. Dispose the old instance, derive a fresh visible document from the canonical JSON, create the replacement, define shapes, load, and fit. Never mutate the canonical ERD merely to hide an entity.
