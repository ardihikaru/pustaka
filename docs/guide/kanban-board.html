Kanban board

A DOM-first board sample with drag-and-drop cards, provider-backed state, and JSON export. This is not a Sisflow canvas diagram.

Live kanban board

The embedded board is pure DOM: cards move between columns, counts update in place, and the host can export the current board state without a canvas layer. The lanes are arranged explicitly left-to-right so the flow reads like a real Kanban board. Use fullscreen to let the columns breathe and make the work-in-progress flow feel like the real thing.

Sample behavior

The board uses the standard Kanban lane model: a card has one current column, columns own their counts, and drop events update the card status immediately. Use fullscreen to let the columns breathe and make the directional flow obvious.

BehaviorNotes
Drag cardsCards move between lanes by native drag-and-drop.

Provider and export notes

The provider is a plain JSON object with `columns` and `cards`. Export keeps that shape so a host app can persist the board, diff it, or feed it into a backend API without translation.

};
function exportBoard(state) {
  return new Blob([JSON.stringify(state, null, 2)], { type: 'application/json' });
}

Embedding

Because the board is DOM-first, it can be embedded in plain HTML, a CMS page, or an application shell without a diagramming runtime. The host only needs a container with an explicit height.

Lifecycle

Keep the provider as the source of truth, then rebuild the board from that provider when the view changes. That keeps drag-and-drop, counts, and export aligned.
